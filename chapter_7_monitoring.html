4. Alarm 설정

resource "aws_cloudwatch_metric_alarm" "high_cpu" {
  alarm_name          = "ecs-high-cpu"
  comparison_operator = "GreaterThanThreshold"
  evaluation_periods  = 2
  metric_name         = "CPUUtilization"
  namespace           = "AWS/ECS"
  period              = 60
  statistic           = "Average"
  threshold           = 80
}

5. 장애 대응 플레이북

  • ALB 502 → Target Health, App Logs, Port 확인
  • ECS Crash → CloudWatch Logs 확인
  • EKS CrashLoopBackOff → kubectl logs/describe
  • DB Slow → Connections, Slow Query, CPU
  • DynamoDB Throttle → Partition Key 설계 확인

6. 기능경기 체크리스트

  • CloudWatch Logs 활성화

  • ECS/EKS 로그 확인
  • DB Connection 확인
  • Alarm 구성 여부 확인

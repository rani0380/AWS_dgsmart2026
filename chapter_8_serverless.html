1. 서버리스 개요

서버리스는 서버를 직접 관리하지 않고 이벤트 기반으로 코드를 실행하는 아키텍처이다. 기능경기 자동화 과제에서 Lambda, API Gateway, SQS, SNS, EventBridge 조합이 자주 사용된다.

Lambda코드 실행
API GatewayHTTP API 진입점
SQS비동기 메시지 큐
SNS알림/팬아웃

2. 대표 아키텍처

Client ↓ API Gateway ↓ Lambda ↓ DynamoDB App ↓ SQS ↓ Lambda Worker ↓ SNS Notification EventBridge Schedule ↓ Lambda

3. Lambda

def lambda_handler(event, context):
    return {
        'statusCode': 200,
        'body': 'Hello Skills'
    }
항목설명
Timeout최대 실행 시간
MemoryCPU 성능에도 영향
Environment Variables설정값 저장
IAM RoleAWS 서비스 접근 권한

4. API Gateway

외부 HTTP 요청을 Lambda로 전달한다.

Client → API Gateway → Lambda → DynamoDB
502 오류는 Lambda 응답 형식 오류 또는 내부 예외일 수 있다.

5. SQS

개념설명
Standard Queue고성능, 중복 가능성 있음
FIFO Queue순서 보장
DLQ실패 메시지 보관
App → SQS → Lambda Consumer

6. SNS

SNS는 하나의 메시지를 여러 구독자에게 전달하는 Pub/Sub 서비스이다.

Lambda → SNS → Email / SMS / Lambda / SQS

7. EventBridge

cron(0 9 * * ? *)

정기 스케줄 실행 또는 AWS 이벤트 기반 자동 실행에 사용한다.

8. Terraform 예시

resource "aws_lambda_function" "main" {
  function_name = "skills-function"
  role          = aws_iam_role.lambda.arn
  handler       = "lambda_function.lambda_handler"
  runtime       = "python3.11"
}

9. 장애 대응

  • Lambda Timeout → timeout 증가, 외부 API 지연 확인
  • AccessDenied → IAM Role 확인
  • SQS 적체 → Lambda Trigger 확인
  • API 502 → Lambda 로그 확인
  • DynamoDB Access 오류 → IAM 정책 확인

10. 기능경기 체크리스트

  • Lambda Role 권한 확인
  • API Gateway 테스트
  • SQS Queue 연결
  • CloudWatch Logs 확인
  • EventBridge Trigger 동작 확인

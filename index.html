✅ 대회 당일 기본 체크리스트

  • AWS CLI 자격 증명이 정상 설정되었는가?
  • Region이 문제 요구사항과 일치하는가?
  • Terraform init, fmt, validate, plan, apply 순서를 지켰는가?
  • VPC, Subnet, Route Table, Security Group 이름이 요구사항과 일치하는가?
  • ECR 이미지 Push가 완료되었는가?
  • ECS Task 또는 EKS Pod가 Running 상태인가?
  • ALB Target Group Health Check가 Healthy 상태인가?
  • CloudWatch Logs에 오류가 없는가?
  • 브라우저 또는 curl로 최종 URL 응답을 확인했는가?

💡 학습 팁

1. 먼저 네트워크를 잡기 대부분의 장애는 VPC, Route Table, Security Group에서 발생합니다.
2. 로그를 먼저 보기 추측하지 말고 CloudWatch Logs, kubectl logs, describe 결과를 먼저 확인합니다.
3. Terraform으로 반복 연습 같은 인프라를 여러 번 생성·삭제하면서 코드 구조를 익힙니다.
4. 최종 검증까지 하기 리소스 생성이 끝이 아니라 실제 서비스 접속 성공이 최종 목표입니다.

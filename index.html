학습 목표

이 사이트는 AWS 콘솔 조작만 외우는 자료가 아니라, 장애 원인을 찾고 서비스가 실제로 동작하는지 검증하는 실전형 학습 자료입니다. 각 챕터는 기능경기 과제에서 자주 만나는 서비스 구성, 명령어, 체크리스트를 중심으로 정리되어 있습니다.

구축VPC, ECS, EKS, RDS, Lambda 같은 AWS 리소스를 목적에 맞게 구성합니다.
검증로그, 메트릭, 헬스체크, CLI 명령으로 정상 동작을 확인합니다.
장애 대응접속 실패, 배포 실패, 권한 오류, 성능 문제를 단계적으로 분석합니다.
